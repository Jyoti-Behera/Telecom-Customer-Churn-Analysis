# Telecom-Customer-Churn-Analysis

## Description
A Power BI dashboard developed to analyze customer churn behavior and identify the major factors affecting customer retention in a telecom company.

## Project Overview
This project focuses on understanding customer attrition patterns using interactive visualizations and business intelligence techniques. The dashboard helps analyze how factors like contract type, tenure, internet services, and monthly charges impact customer churn.

## Features
- Churn Distribution Analysis
- Churn by Contract Type
- Churn by Gender
- Churn by Tenure
- Churn by Monthly Charges
- Churn by Internet Services
- Interactive Filters and Slicers

## Tools & Technologies
- Power BI
- DAX
- Data Visualization
- Data Cleaning
- Business Intelligence

## Dataset Information
The dataset contains telecom customer information including:
- Customer Demographics
- Contract Details
- Internet Services
- Monthly Charges
- Tenure
- Churn Status

## Business Insights
- Month-to-Month customers have the highest churn rate.
- Fiber Optic users are more likely to churn.
- Customers with shorter tenure show higher churn probability.
- Higher monthly charges are associated with increased churn.
